Three pages, one folder

The notebook, this guide, and the gallery are separate files. A link such as guide.html has no folder in it, so the browser looks next to the page you clicked from.

  • Bird notebook — a sightings table, a form, and several ways to load the bird picture.
  • Guide — this page. It describes the folder.
  • Gallery — the bird picture on its own, with a note on where the file lives.

How you arrived

If this tab replaced the notebook, you followed Open the guide in this tab. The address bar should end in playground/guide.html.

The Gallery link on the notebook uses target="_blank". That one keeps the notebook open and puts the Gallery in a new tab.

Graded exercises live in the practices/ folder, one level above this one.
