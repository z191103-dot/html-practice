Sightings table

A table is for data that lines up in rows and columns. thead holds the column names. tbody holds the records. Every row has the same number of cells, so the columns stay aligned. scope tells a screen reader whether a heading names a column or a row.

Sighting form

Use this form to record a bird you saw. Each control has a label, and the label's for matches the control's id. Clicking the label focuses the matching field. required means the browser will not submit until that field is filled in. action="/submit" and method="post" say where the data would be sent. There is no server at /submit in this repository, so a successful submit still ends in an error page.

The sighting



How to reach you



10 digits, with no spaces. type="tel" asks the browser for a telephone keypad.



type="email" checks that the value looks like an email address.

When and how many



type="number" with min and max limits the count to 1–100.



type="date" opens a date picker. The date must fall between 1 January 2020 and 15 October 2026.
