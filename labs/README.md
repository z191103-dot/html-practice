## How to open a lab

Finish lesson 01 before lesson 02. The practice folders cover the same early subjects in [lesson 01](../practices/lesson-01/README.md) and [lesson 02](../practices/lesson-02/README.md). Lab 02 is HTML Lesson 2: Beyond the Basics, and it lives in `labs/lesson-02/`.

Students run each lab in Colab from their own fork. The lesson 01 badge on the [course README](../README.md) uses the same notebook as the first link below.

1. Fork this repository on GitHub.
2. In your fork, replace `morbargig` in each **Open in Colab** link with your own GitHub username.
3. Open the lab from that updated link.
4. In Colab, select **File → Save a copy in Drive**. Work only on your own copy.

A link in this repository looks like this:

`https://colab.research.google.com/github/morbargig/html-practice/blob/main/labs/lesson-01/lab-01-html-fundamentals.ipynb`

After the fork, the same link uses your username:

`https://colab.research.google.com/github/YOUR_USERNAME/html-practice/blob/main/labs/lesson-01/lab-01-html-fundamentals.ipynb`

Assignments and class materials are in [Google Classroom](https://classroom.google.com/w/ODkxNzk1OTQwMDY3/t/all).

## Lesson 02 — Advanced HTML & Native Interactivity

**HTML Lesson 2: Beyond the Basics.** Build an interactive student portal with HTML only.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/morbargig/html-practice/blob/main/labs/lesson-02/Lab_02_Advanced_HTML_Native_Interactivity.ipynb)

Notebook: [lesson-02/Lab_02_Advanced_HTML_Native_Interactivity.ipynb](lesson-02/Lab_02_Advanced_HTML_Native_Interactivity.ipynb)

The notebook saves each exercise as an HTML file and previews it in Colab.

- Setup: HTML preview helper
- Exercise A — Attributes and advanced inputs
- Exercise B — Fieldset, legend, and datalist
- Exercise C — Native interactive HTML
- Exercise D — Progress and meter
- Final challenge — Interactive student portal
- Self-check and reflection

Topics: attributes, advanced inputs, fieldsets, datalist, details/summary, popovers, dialogs, progress, and meter.

Colab's preview can restrict popovers and dialogs. Download the HTML file and open it in a current browser with VS Code and Live Server. Install steps are in [extensions/README.md](../extensions/README.md). Dialog buttons use `command` and `commandfor`, which need a current browser. The page uses HTML only.
