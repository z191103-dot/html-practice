# 02 — A Simple Form

## 📚 Subject
A form that asks for an email address before it can be sent.

## 📖 Read About It
- MDN: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form
- W3Schools: https://www.w3schools.com/html/html_forms.asp

## 🎯 Task
Create a form with an email field and a button.

The label text is `Email:`. The input type is `email`, and the field is `required`. The button text is `Send`.

## ✅ Requirements
- Use one `<form>`.
- Put the label, input, and button inside the form.
- Use `<input type="email" required>`.
- Use a `<button>` with the text `Send`.
- Do not modify the test files.

## 🧪 Testing
From the repository root, run:

```bash
npm test -- 02-simple-form
```

`npm test` checks every practice.
