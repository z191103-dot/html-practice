# 01 — An Unordered List

## 📚 Subject
A bulleted list of short items.

## 📖 Read About It
- MDN: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ul
- W3Schools: https://www.w3schools.com/html/html_lists.asp

## 🎯 Task
Create a bulleted list of three things you have practiced:

1. Headings
2. Links
3. Images

Use `<ul>` and `<li>`. Keep that order.

## ✅ Requirements
- Use one `<ul>`.
- The three items must be exactly `Headings`, `Links`, and `Images`.
- Do not modify the test files.

## 🧪 Testing
From the repository root, run:

```bash
npm test -- 01-unordered-list
```

`npm test` checks every practice.
